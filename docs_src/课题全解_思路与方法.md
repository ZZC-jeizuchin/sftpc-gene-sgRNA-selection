# 课题全解：从零理解这个项目

> 这份文档的目标是：**读完你就能把这个课题从头到尾讲给任何人听**，
> 包括不懂生物信息学的评委、家长、同学。
> 每一节都按「为什么需要这个概念 → 它是什么 → 我们怎么用」的顺序写。

## 0. 一页纸看懂

**一句话**：我们做了一个网页工具，帮研究者从几百条候选 sgRNA 里，挑出
**最有可能"只切致病的那条基因、不碰正常那条"** 的几条去做实验。

**为什么需要**：现有两大网站（CRISPOR、CHOPCHOP）能生成几百条候选，
但它们的排序是"通用场景"的，不考虑"你手上这个具体的致病突变"。
研究者拿到的是一堆数字，还得自己人工比对、手动算分。

**我们做了什么**：
1. 用程序自动去两个网站取数（它们没有 API，我们反向工程了接口）；
2. 两个网站的"位置"含义不一样，我们统一了口径（416/416 逐条验证一致）；
3. 按实验经验做硬性过滤，淘汰明显不合格的；
4. **加了第四个评分维度**：这条 sgRNA 能不能区分"突变型"和"野生型"两条等位基因；
5. 加权排序，做成网页，开源。

**最有价值的部分**：过程中我们**三次推翻了自己最初的假设**。
详见第 4 节——这也是评委最想听的部分。

## 1. 背景知识（从零讲起）

### 1.1 DNA、基因、突变

- **DNA** 是由 A/T/C/G 四种碱基连成的长链，人类基因组约 30 亿个碱基对。
- **基因**是 DNA 上的一段，编码一个蛋白质。
- **突变**就是某个位置的碱基换了。比如 `T` 变成 `C`。
- **致病突变**：换掉的这个碱基让蛋白质出错，导致疾病。

### 1.2 CRISPR-Cas9 是怎么"剪"DNA 的

把它想成**"分子剪刀 + 导航"**：

- **Cas9 蛋白** = 剪刀
- **sgRNA**（single guide RNA）= 导航，一段约 20 个碱基的 RNA
- 导航带 Cas9 去找 DNA 上**与它互补**的那段序列，找到就剪

关键概念：

| 概念 | 含义 |
|---|---|
| **spacer** | sgRNA 上那 20 个碱基的"导航序列" |
| **PAM** | DNA 上紧挨着目标序列的 3 个碱基，SpCas9 要求是 `NGG`。**没有 PAM 就不剪** |
| **23mer** | spacer(20) + PAM(3) = 23 个碱基，是设计工具最常报的区间 |
| **切割位点** | 剪刀实际下刀的位置，在 PAM 上游（靠 5′ 那侧）3 个碱基处 |
| **Seed 区** | spacer 上**紧邻 PAM** 的那 8–12 个碱基。这一段配对不上，Cas9 就切不动 |
| **脱靶** | 剪到了不该剪的地方（因为基因组里可能有相似的序列） |

**Seed 区为什么重要？** 这是全项目的核心之一：
种子区相当于"最后一道锁"，PAM 先认出位置，种子区再确认配对。
**种子区有错配 → 大概率切不动；PAM 远端有错配 → 影响小得多。**

### 1.3 为什么"选哪条 sgRNA"是个大问题

同一个基因上，能当 sgRNA 的位置有几百个。它们之间差别巨大：

- 有的切得又快又准（好）
- 有的切不动（没用）
- 有的到处乱切（危险）
- 有的对你关心的那个突变位点毫无区分能力（详见 1.5）

**现有工具只负责"列出选项"，不负责"帮你选"。** 这就是我们要解决的"最后一公里"。

### 1.4 两个主流网站：CRISPOR 与 CHOPCHOP

| | CRISPOR | CHOPCHOP |
|---|---|---|
| 干什么 | 输入序列，列出所有候选 sgRNA 并打分 | 同上 |
| 特色 | 集成多种评分算法（Doench'16、CFD 等） | 支持多种核酸酶、多种应用场景 |
| 有没有 API | **没有** | **没有** |

**关键坑（我们踩过）**：两个网站报的"位置"数字含义不一样！

- CRISPOR 报的是 **PAM 区间的左端**
- CHOPCHOP 报的是 **23mer 的最左端**

差了 20 个碱基。直接相减的话，正链会系统性差 20 bp，反链反而碰巧重合——
这会让人误以为"只是小误差"，其实锚点根本不同。

### 1.5 这个课题真正的医学背景：等位基因特异性编辑

**SFTPC 基因**编码肺表面活性物质蛋白 C。它的突变会导致**儿童间质性肺病**，
其中最常见的是 **I73T（c.218T>C）**。

这个病是**常染色体显性遗传**——患者只带**一个**突变拷贝（另一条是正常的）。
用 `+/−` 表示：`+` 是正常等位基因，`−` 是突变等位基因。

所以理想的治疗思路是：**只破坏 `−`，保留 `+`**。这叫**等位基因特异性编辑**。

要做到这一点，sgRNA 必须**能区分两条只差一个碱基的序列**。
问题是——**Cas9 能不能分辨一个碱基的差别？**

能，但取决于这个碱基落在哪：

- 落在 **PAM** 里 → 突变型根本没有 PAM，Cas9 完全不去 → 区分最彻底
- 落在 **Seed 区** → 错配严重影响结合 → 区分较好
- 落在 **PAM 远端** → Cas9 不太在意 → 两条都切，没有区分能力

**"切点离突变近"只是必要条件，不是充分条件。**
一条 sgRNA 可能切点就在突变位点上，但如果它对两条等位基因的亲和力一样，
它会**两条都切**，等位基因特异性无从谈起。这就是我们后来加第四维的原因。

## 2. 我们把问题定义成什么

```
输入：一段 DNA 序列 + 一个突变位点坐标
输出：按"值得先试"排序的候选 sgRNA 清单（附每条的四维得分）
约束：只做二次筛选，不从头设计序列
```

**"二次筛选"是什么意思？** 我们不去发明新的 sgRNA 序列，
而是把两个网站**已经给出**的候选收集起来，重新打分、重新排序。
这就像：不是自己去种菜，而是把两个菜市场的菜挑出来，按你要做的菜重新排个序。

## 3. 方法原理（逐条讲透）

### 3.1 为什么要"调接口"而不是"查网站"

手动流程：打开 CRISPOR → 粘贴序列 → 等 → 下载 → 再打开 CHOPCHOP → 重复 → 用 Excel 手动比对。

**问题**：慢、易错、不可复现、换一条序列又要重来。

我们做的是：写程序模拟浏览器的请求，直接拿到结果文件。
另外做了一个优化：**结果没算好之前，不去反复刷新几百 KB 的结果页，而是轮询几 KB 的下载端点**——
把首次查询从两分多钟压到三十秒。

### 3.2 坐标归一化：为什么必须做

前面说过两站锚点不同。我们的做法是：**把两者都换算到"切割位点"**。

```
CRISPOR：  PAM 左端  →  切割位点 = PAM左端 − 3（正链）
CHOPCHOP： 23mer 左端 →  先换成 PAM 左端，再 − 3
```

然后**逐条验证**：把两站共有的 416 条 guide 一条条比对切割位点，
结果 **416/416 完全一致**。

**为什么这一步这么重要？** 如果不一致，后面的所有评分都建立在错位的坐标上，
整个工具都是错的。这是"地基"。

> 从这里我们学到一条原则：**字段同名 ≠ 语义等价。数据源可比性必须先校验。**

### 3.3 硬性过滤：先把明显不合格的扔掉

这是实验经验的规则化，任一条不满足直接淘汰：

| 规则 | 阈值 | 为什么 |
|---|---|---|
| spacer 长度 | 恰好 20 nt | SpCas9 标准，多一个少一个都不行 |
| PAM | 必须 NGG | SpCas9 只认这个 |
| GC 含量 | 40%–70% | 太低结合不稳，太高易形成二级结构 |
| 终止信号 | 不能含 TTTT | U6 启动子会在这里提前停止转录，sgRNA 变短失效 |
| 连续同碱基 | ≤4 个 | 合成质量差、容易滑链错配 |
| 去重 | 相同 spacer 留一条 | 两站可能给出重复 |

### 3.4 评分维度一：切割效率（Doench '16）

**它是什么**：Doench 等人在 2016 年用大量实验数据训练出的模型，
预测"这条 sgRNA 切得动吗"，输出 0–100 的分数。

**怎么理解**：类似"这条鱼竿能钓上鱼的把握"。分数越高越可能切得动。

**注意**：它是 0–100 的**整数分**，不是概率百分比。
一个碱基的差别通常只让它变动几个点——**这一点后来害了我们，见 4.3**。

### 3.5 评分维度二：脱靶特异性（CFD）

**它是什么**：CFD = Cutting Frequency Determination，
量化"错配会让切割频率下降多少"。CFD 越高 = 脱靶风险越低 = 越安全。

**怎么理解**：类似"这把刀会不会切到手"。分数越高越安全。

**关键**：CFD 的本质是一张**错配惩罚表**：20 个位置 × 12 种错配类型，
每个格子告诉你"这个位置这种错配，还剩多少切割活性"。

**我们后来用这张表做了独立验证**，见 3.8。

### 3.6 评分维度三：突变距离

**它是什么**：切割位点到突变位点的碱基距离。越近越好。

**为什么**：

- 若目的是**修正**突变（HDR 修复），切点离目标越近，修复效率越高
- 若目的是**只破坏突变型**，切点必须靠近突变才能"只影响这一条"

分档给分：≤20 bp = 100，≤50 = 90，≤100 = 70，≤200 = 40，>200 = 10；
如果 20 nt 区间直接盖住突变位点，再 +10（封顶 100）。

**重要**：这是 v1 的**核心维度**，但在 v2 里权重从 23.5% 降到了 10%。
为什么？因为它是**代理指标**，不是真正的目标——见 4.2。

### 3.7 评分维度四：等位基因特异性（v2 新增，核心创新）

这是本项目最需要讲清楚的东西。

#### 3.7.1 要回答的问题

> 这条 sgRNA 是**只切突变型**，还是**两条都切**？

#### 3.7.2 怎么量化：ΔScore

**思路**：把两条序列分别交给同一个模型打分，看差多少。

```
Δraw   = Doench(突变型序列) − Doench(野生型序列)
```

- 如果这条 sgRNA 的 23mer **不覆盖突变位点**，那么它在两条序列上完全一样，
  Δraw 必然 = 0。**这在生物学上是对的**：不覆盖突变，就不可能区分两条等位基因。
- **Δraw > 0**：突变型切得更好 → 偏爱突变型 → 好
- **Δraw < 0**：野生型切得更好 → 会先切坏正常基因 → 不好

#### 3.7.3 为什么要归一化成 ΔScore

Δraw 是"Doench 分的差"，单位是 Doench 分，范围大约 −20…+20。
但后面的规则（"ΔScore < 20 就降权"）是按 **0–100 的特异性分**设计的。

所以必须换算：

```
ΔScore = 100 × clamp(Δraw, 0, 20) / 20
```

意思是：**Doench 差 20 分算满分**。这个 20 不是随便定的，
详见 4.3——这是我们踩坑后修出来的。

#### 3.7.4 位置分：突变落在哪很重要

| 突变位置 | 距 PAM 第几位 | 位置分 | 为什么 |
|---|---|---|---|
| PAM 区 | 21–23 | 100 | NGG 被改掉，突变型根本没 PAM |
| Seed 区 | 1–8 | 80 | 错配严重破坏配对稳定性 |
| 中间区 | 9–14 | 40 | 中等 |
| PAM 远端 | 15–20 | 10 | 错配耐受性高 |
| **不覆盖** | — | **0** | 物理上无法区分 |

> **注意编号方向**：这里"第 1 位"指**紧邻 PAM** 的那一位。
> 这个方向很容易搞反，我们在做 CFD 验证时就搞反过一次，见 4.3 的坑。

#### 3.7.5 合成

```
等位基因特异性 = 0.6 × ΔScore + 0.4 × 位置分
降权：ΔScore < 20 时，整体 × 0.3
```

**降权规则的意义**：如果两条序列切得差不多（ΔScore 很小），
即使位置分很高，也说明这条 sgRNA 区分能力差，所以要打压。

### 3.8 为什么要用 CFD 做"外部佐证"

**问题**：评委一定会问"你的评分准不准？有证据吗？"

**难点**：我们没有湿实验数据，也没有公开的实测数据集。

**我们的做法**：找一个**独立模型**来检验**设计原则**。

- CRISPOR 和 CHOPCHOP 的分数是同一个模型（见 4.4），互相验证没有意义
- **CFD 是另一个模型**：它是从实验数据拟合出来的错配惩罚表

**检验什么**：如果我们说"Seed 区错配影响大、PAM 远端影响小"，
那 CFD 的真实数据也应该显示同样的趋势。

**结果**：

- CFO 的平均错配惩罚：Seed 区 0.596，PAM 远端 0.287 → **Seed 是远端的 2.08 倍**
- 与我们的位置分做 Spearman 相关：**ρ = 0.816**

**这说明**：我们的位置分设计不是拍脑袋，跟独立的实验数据拟合结果同向。

**但要诚实地说清楚局限**：CFD 只能证明"我们的**设计原则**与文献一致"，
**不能**证明"我们的**排序**与实验结果一致"。后者只能靠实验。

### 3.9 权重从哪来（这是评委最爱问的）

我们用了三条独立证据：

#### 证据一：CRITIC 客观赋权

CRITIC 是一种只用数据本身算权重的经典方法。它的逻辑：

- **对比强度**：这一维数据本身差异大不大（标准差）
- **冲突性**：这一维和其他维度的相关性低不低（越低，说明它提供的信息越"独立"）
- 权重 ∝ 对比强度 × 冲突性

**结果**：等位基因特异性 10.3%，效率 25.9%，脱靶 26.8%，距离 36.9%。

**和我们的 35/30/25/10 严重分歧！**

**怎么解释**（这段一定要会讲）：

> 等位基因特异性在 313 条里有 **307 条是 0**（不覆盖突变就物理上无法区分）。
> 数据极其稀疏，标准差只有 0.075；而距离是分档的、分布铺得开，标准差 0.256。
> CRITIC 是**纯方差驱动**的，自然会把稀疏的那一维看轻。
>
> **但 CRITIC 回答的是"哪个维度区分度大"，不是"哪个维度对目标更重要"。**
> 我们的目标是等位基因特异性编辑——"能不能区分两条等位基因"是**先决条件**，
> 所以 35% 是一个**目标驱动的价值判断**，不是从数据推导出来的结论。

**这个分歧本身不是缺点，是诚实。** 说清楚比假装一致好。

#### 证据二：敏感性分析

把 ASS 权重在 0 / 10 / 20 / 35% 四档下各算一遍：

| ASS 权重 | Top-1 | 分数 | ≥70 分条数 |
|---|---|---|---|
| 0% | 某条不覆盖突变的 | 82.77 | 14 |
| 10% | GGTTCTGGAGATGAGCATTGGGG | 76.40 | 3 |
| 20% | 同一条 | 73.80 | 1 |
| 35% | 同一条 | 69.90 | 0 |

有意思的是：**10–20% 区间既能让"真正能区分"的 guide 排到第一，又保留可读的分数分布**。
这与 CRITIC 的 10.3% 独立地指向同一区间。

#### 证据三：消融实验

去掉某一维，其余按比例重新归一化，看排序怎么变：

| 去掉的维度 | Top-1 是否变化 | Top-10 重合 | 与基准排序 ρ |
|---|---|---|---|
| 切割效率 | 是 | 60% | 0.760 |
| 突变距离 | 否 | **30%** | 0.903 |
| 等位基因特异性 | 是 | 80% | 0.999 |
| 脱靶特异性 | 否 | 90% | 0.747 |

**怎么解读**：
- **效率管全表**：去掉后全表秩相关掉到 0.760，影响面最广
- **距离管头部**：权重只有 10%，但去掉后 Top-10 只剩 30% 重合——它决定前几名是谁
- **脱靶影响最小**：CRISPOR 初筛已经压掉大批高脱靶候选，进来的都不差
- **等位基因特异性只动头部**：ρ=0.999 但 Top-10 掉到 80%——这正是设计意图

#### 最终决定

保留 **35% 作为默认**（"等位基因特异性优先"），
同时提供 **15% 的"均衡"预设**，网页上可以切换对比。

**两套都留着，因为它们是两种不同的价值取向，不是谁对谁错。**

### 3.10 为什么等级用"分位"而不是分数线

**问题**：一开始用 90/80/70/60 的固定分数线，结果 **313 条里 311 条是"不推荐"**。

**原因**（这是结构性的，不是参数没调好）：

- 307/313 条 guide 的等位基因特异性是 0
- 所以综合分的**上限**只有 `0.30×100 + 0.25×100 + 0.10×100 = 65`
- 任何高于 65 的阈值永远达不到

**修正**：改用**分位**——"在这批候选里排前百分之几"。

最终：优先推荐 16 条（前 5%）、推荐 47 条（5%–20%）、可选 94 条（20%–50%）、
备选 156 条（其余）。

**分位在任何数据分布下都成立**，也不会给人"65 分就是不及格"的误解。

## 4. 四次迭代：我们是怎么一步步发现自己错了的

> **这一节是全项目的灵魂。** 评委看的就是这个。
> 好的研究不是"一次就做对"，而是"能发现自己哪里错了"。

### 4.1 v1：三维修（2026 年 10 月）

方案：切割效率 41.2% + 脱靶 35.3% + 突变距离 23.5%。

结果：434 条候选，416 条共有，过滤后 313 条；
第一名 `GGTTCTGGAGATGAGCATTGGGG`，切点距突变 0 bp，得分 91.73/100；
坐标一致性 416/416。已上线并开源。

### 4.2 第一次迭代：距离近 ≠ 只切突变型

**我们的假设**：切点越靠近突变越好。

**问题**：一条 sgRNA 即使切点紧贴突变，如果它对野生型和突变型的切割效率**几乎相同**，
它会把两条等位基因都切掉——等位基因特异性编辑的意义完全丧失。

**结论**：距离只是**代理指标**，不是目标本身。

**修正**：
1. 新增第四维「等位基因特异性」（ΔScore + 位置分）
2. 距离权重从 23.5% 降到 10%（降为辅助）
3. 三维统一到 0–100 分制

### 4.3 第二次迭代：ΔScore 的量纲错了 ⚠️

**现象**：按公式做完，**313 条全部"不推荐"，最高分只有 55.15**。

**定位过程**：
1. 先怀疑位置分算错了 → 查了，没错
2. 再怀疑降权规则 → 发现降权触发的比例是 **100%**，不正常
3. 打印 Δraw 的分布 → 发现 **434 条里只有 7 条 Δraw ≠ 0，最大 10 分，中位数 1 分**
4. 明白了：Doench'16 是 0–100 整数分，**一个碱基只让它动几个点**；
   而"ΔScore < 20 就降权"这条规则来自 CRISPRseek，它的差值是 0–100 的特异性分，
   一个错配能让它掉几十点

**病根**：**把两个不同量纲的数相减。** 结果所有 guide 的 ΔScore 都 < 20，
降权规则 100% 命中，35% 的那一维被整体 ×0.3 打趴。

**修正**：加固定锚做归一化 —— `ΔScore = 100 × clamp(Δraw, 0, 20) / 20`
（Doench 差 20 分 = 满分）。

**效果**：Top-1 从 55.15 回到 69.90，Top-2 62.70，区分度恢复。

> **这个教训有普遍性**：不同平台的分数不可跨量纲直接相减。
> 任何新维度接入前，必须先做量纲标定。

### 4.4 第三次迭代：两个平台其实是同一个模型 ⚠️

**我们的假设**：CRISPOR 和 CHOPCHOP 是两套独立算法，「两站取平均」能提升精度。

**检验方法**：把 CRISPOR 的 `Doench'16` 和 CHOPCHOP 的 `Efficiency` 按位置配对
（416 条全部匹配上），算相关系数。

**结果**：Spearman ρ = **0.9992**，Pearson r = 0.9994，均值 50.6 vs 50.64。

**结论**：CHOPCHOP 的 Efficiency 用的也是 Doench 2016 / Azimuth 那套模型。
**两个平台给的是同一个预测，不是两个独立证据。**

**三个连带修正**：
1. **放弃"两站取平均"**——对同一个数取平均还是那个数
2. **放弃"多工具共识降低偏差"的说法**——在 on-target 效率这项上不成立
3. **重新定位工具价值**：不在"算法多样"，而在
   **候选并集更全 + 坐标口径统一并交叉验证 + 硬性过滤 + 突变背景下的重排序**

> 这是一个**否证自己假设**的例子。能这样做，比硬撑着说"我们用了多个工具所以更可靠"强得多。

### 4.5 第四次迭代：等级不能用固定分数线

见 3.10。

## 5. 三层验证体系（答"你凭什么说它有效"）

没有湿实验时，我们建立了三层验证：

| 层级 | 验证什么 | 方法 | 结果 |
|---|---|---|---|
| **坐标层** | 数据对齐对不对 | 两站共有 guide 逐条比对 | **416/416 一致** |
| **模型层** | 设计原则对不对 | CFD 独立模型（Doench 2016 实验拟合） | 位置分 ρ=**0.816**，Seed 惩罚是远端 2.08 倍 |
| **设计层** | 权重与结论稳不稳 | CRITIC + 消融 + 稳定性 + 多基因 | 见 3.9、5.1、5.2 |

### 5.1 稳定性分析

在基准权重附近随机扰动 2000 次（Dirichlet 分布）：

- **Top-1 稳定 99.2%**（权重怎么抖，第一名都不变）
- **Top-10 平均重合 77.3%**（最低 20%）

**结论**：论文和答辩**不要只说"排名第一的那条"**，要报一个 3–5 条的**候选短名单**。
这既诚实，也符合实验现实——没人只做一条。

### 5.2 多基因通用性

为排除"只对 SFTPC 调参"的质疑，我们在 **HBB（镰状细胞病）** 上完整复跑。

选它的理由：① 它是**负链**基因，检验链向处理；② 突变定义无争议（rs334）；
③ 疾病场景完全不同。

| 指标 | SFTPC（正链） | HBB（负链） |
|---|---|---|
| 位置 | chr8:22,163,096 | chr11:5,227,002 |
| CRISPOR / CHOPCHOP | 434 / 416 | 152 / 148 |
| 过滤后 | 313 | 99 |
| 覆盖突变 | 6（1.9%） | 3（3.0%） |
| Top-1 | GGTTCTGGAGATGAGCATTGGGG（69.90） | GTAACGGCAGACTTCTCCTCAGG（69.25） |
| Top-1 覆盖突变 | 是（Δraw +7） | 是（Δraw +9） |

**两案 Top-1 都覆盖突变位点、Δraw 都 > 0。**

**注意覆盖数少是几何必然**：23 nt 窗口要恰好盖住一个特定碱基。
SFTPC 313 条里只有 6 条，HBB 99 条里只有 3 条——比例相近，不是 bug。

## 7. 答辩常见问题与回答

**Q1：你们的创新点是什么？**
> 我们没有发明新算法。我们的贡献是把评分从「单序列」扩展到「双序列」，
> 用同一模型对野生型和突变型分别打分求差，量化「这条 sgRNA 能不能只切突变型」。
> 并且在实施过程中发现并解决了两个真实问题：跨平台分数的量纲不可比，
> 以及两个平台其实是同一个模型。

**Q2：为什么权重是 35%？凭什么不是 25%？**
> 我们做了 CRITIC 客观赋权，它给出 10.3%。但我们没有直接采用，因为
> CRITIC 是方差驱动的，它回答「哪个维度区分度大」，不回答「哪个维度对目标更重要」。
> 等位基因特异性在 313 条里 307 条是 0，非常稀疏，所以 CRITIC 会看轻它。
> 我们的目标是等位基因特异性编辑，所以 35% 是一个**价值判断**，不是数据推导。
> 同时我们提供了 15% 的均衡预设，两套都可以切换。

**Q3：你的评分准不准？有实验验证吗？**
> 没有湿实验，这是我们最大的局限。我们用 CFD 独立模型做了设计验证：
> 位置分与 CFD 错配惩罚的 Spearman ρ=0.816，Seed 区惩罚是 PAM 远端的 2.08 倍。
> 但这只能证明「设计原则与文献一致」，不能证明「排序与实验结果一致」。
> 下一步做体外切割实验，方案已经设计好了。

**Q4：两个网站的数据能直接比吗？**
> 不能。我们实测 CRISPOR 的 Doench'16 和 CHOPCHOP 的 Efficiency
> Spearman ρ=0.9992——它们其实是同一个模型。所以我们放弃了「两站取平均」的做法。
> 这也说明「多工具共识」在这一项上不成立。

**Q5：为什么覆盖突变的 guide 只有 6 条？是不是筛掉了？**
> 不是几何筛选，是几何必然。23 nt 的窗口必须恰好盖住一个特定碱基，
> 一个 2213 bp 的序列里能盖住某一特定位点的窗口就那么几个。
> 这是所有方法共同的约束，不是我们的工具造成的。

**Q6：排名第一的 sgRNA 一定最好吗？**
> 不一定。我们做了稳定性分析：权重扰动 2000 次，Top-1 稳定 99.2%，
> 但 Top-10 平均重合只有 77.3%。所以我们建议报 3–5 条的**候选短名单**，
> 而不是押在一条上。事实上模拟实验显示，排名第二的 AGGTTCT… 等位基因特异性
> （1.34）反而比第一名的 GGTTCT…（1.08）更好——这就是「效率 vs 特异性」的取舍。

**Q7：这个工具和 AsCRISPR / CRISPRseek 有什么区别？**
> CRISPRseek 的 compare2Sequences 能做双序列比较，但需要 R 环境和命令行，
> 而且不做跨平台采集与坐标归一化。AsCRISPR 是「从头设计」。
> 我们的定位是「对已有候选的二次筛选与重排序」，
> 价值在跨源数据的可比性工程 + 突变背景下的重排序。

**Q8：你们用的方法超出高中生水平了吗？**
> 用到的都是公开工具和基本统计：相关系数、加权求和、消融实验。
> CRITIC 和 CFD 都是引用现成的方法与数据，我们做的是理解、应用和验证，
> 不是发明。真正的难点在**发现问题**——比如量纲不对、两站同源，
> 这些是靠打印数据、对比结果才发现的。

## 8. 术语表（速查）

| 术语 | 一句话解释 |
|---|---|
| **sgRNA** | 引导 RNA，Cas9 的「导航」，约 20 nt |
| **spacer** | sgRNA 上那 20 个碱基的导航序列 |
| **PAM** | 目标序列旁 3 个碱基，SpCas9 要求 NGG，没有就不切 |
| **23mer** | spacer(20) + PAM(3) |
| **切割位点** | 实际下刀处，在 PAM 上游 3 bp |
| **Seed 区** | 紧邻 PAM 的 8–12 nt，错配影响最大 |
| **脱靶** | 剪到不该剪的地方 |
| **Doench '16** | 预测 on-target 切割效率的模型，0–100 |
| **CFD** | 量化错配影响、评估脱靶的模型 |
| **等位基因** | 同一个基因的两份拷贝（父源/母源） |
| **等位基因特异性编辑** | 只编辑其中一份，保留另一份 |
| **ΔScore** | 我们的指标：双序列切割效率差，归一化到 0–100 |
| **ASS** | 等位基因特异性评分 = 0.6×ΔScore + 0.4×位置分 |
| **CRITIC** | 一种只用数据算权重的客观赋权方法 |
| **消融实验** | 去掉某一项，看结果变化多少 |
| **Spearman ρ** | 秩相关系数，衡量两个排序的一致性 |
| **分位** | 排在前百分之几 |

## 9. 三句话总结（面试/答辩开场用）

1. **我们做了什么**：把两个没有 API 的 sgRNA 设计网站接起来，统一坐标口径，
   加了一个「能不能只切致病突变」的评分维度，做成网页并开源。
2. **我们发现了什么**：距离近不等于只切突变型；分数不能跨量纲相减；
   两个平台其实是同一个模型——这些都推翻了我们最初的假设。
3. **我们证明了什么**：坐标 416/416 一致；位置分与 CFD 独立模型 ρ=0.816；
   方法在正负链两个基因上都能跑通。**但我们没有湿实验，这是最大局限。**
